# Student Registration System Using Java Swing

**Java Programming – Assignment 10**  
**Deccan Education Society, Pune University**

## Project Overview

A graphical Student Registration System developed using Java Swing. The application provides a simple registration form where users can enter student details and submit their information.

The program uses Java Swing components to create the GUI, ActionListener to handle button events, and ArrayList to store student information temporarily.

## Technologies Used

- Java
- Java Swing
- AWT
- ActionListener
- ArrayList
- Eclipse IDE

## Features

- Graphical user interface for student registration.
- Input fields for student details.
- Submit button to register student information.
- Clear button to reset the form.
- Validation to prevent empty form submissions.
- Temporary data storage using ArrayList.

## How to Run

1. Open Eclipse IDE.
2. Create a Java project.
3. Create a class named `StudentRegistration`.

5. Run the program as a Java Application.
6. Enter student details and click Submit.

This project demonstrates the development of a basic Student Registration System using Java Swing. It helps understand GUI development, event handling, form validation, and temporary data storage using Java Collections.
