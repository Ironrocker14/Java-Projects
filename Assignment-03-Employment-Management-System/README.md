# Employee Management System

**Java Programming – Assignment 3**  
**Deccan Education Society, Pune University**

## Project Overview

A console-based Employee Management System developed using Java to demonstrate different types of inheritance and runtime polymorphism.

The application manages different employee roles, including Employees, Managers, Developers and Senior Managers. It demonstrates code reusability through inheritance and method overriding.

## Concepts Demonstrated

- Single Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Hybrid Inheritance
- Method Overriding
- Runtime Polymorphism
- Parent and Child Classes
- `super` Keyword
- Classes and Objects

## Technologies Used

- **Programming Language:** Java
- **IDE:** Eclipse
- **JDK:** Java Development Kit

## Class Description

| Class | Description |
|---|---|
| Employee | Base class containing common employee details and methods. |
| Manager | Extends Employee and represents a manager. |
| Developer | Extends Employee and represents a developer. |
| SeniorManager | Extends Manager and represents a senior manager. |
| Main | Main class responsible for creating objects and demonstrating inheritance and polymorphism. |

## Features

- Displays employee details.
- Manages different employee roles.
- Demonstrates multilevel and hierarchical inheritance.
- Implements method overriding.
- Demonstrates runtime polymorphism using parent-class references.
- Shows code reusability through inheritance.

## How to Run

1. Open Eclipse IDE.
2. Import or create a Java project.
3. Add all the Java source files.
4. Open `Main.java`.
5. Run the program using **Run As → Java Application**.
